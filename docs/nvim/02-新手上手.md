# 新手上手

这份指南面向从没用过 vim 的人，只讲日常写代码最常用的部分。遇到想不起来的操作，**按一下空格，等半秒**，看弹出的中文菜单就行。

## 一、最重要的概念：模式

vim 和普通编辑器最大的不同是有"模式"：同一个按键，在不同模式下作用不同。

| 模式 | 怎么进入 | 用来做什么 | 左下角显示 |
| --- | --- | --- | --- |
| **普通模式** | 按 `Esc`（任何时候按都会回到这里） | 移动光标、执行命令、删除、复制 | `NORMAL` |
| **插入模式** | 普通模式下按 `i` | 像普通编辑器一样打字 | `INSERT` |
| **可视模式** | 普通模式下按 `v`（按字符）或 `V`（按行） | 选中一段文字，再对它操作 | `VISUAL` |
| **命令模式** | 普通模式下按 `:` | 输入命令，例如 `:w` 保存、`:q` 退出 | 底部出现 `:` |

**记住一条就够了：不知道自己处在什么状态时，按 `Esc`。**

## 二、生存必备

| 操作 | 按键 |
| --- | --- |
| 开始打字 | `i` |
| 停止打字 | `Esc` |
| 保存 | `Ctrl+s`（任何模式都可以），或 `:w` 回车 |
| 退出 | `空格 q q`，或 `:q` 回车 |
| 不保存强制退出 | `:q!` 回车 |
| 撤销 / 重做 | `u` / `Ctrl+r` |
| 上下左右移动 | 方向键即可；熟练后用 `h` `j` `k` `l`，手不用离开主键区 |

> 下文中的"空格"指 **Leader 键**。LazyVim 大部分功能都挂在它下面，例如 `空格 f f` 的意思是：依次按空格、`f`、`f`，不需要同时按住。

## 三、用 which-key 探索快捷键

按下 `空格` 后稍等一下，右下角会弹出菜单：

```
b ➜ +缓冲区（已打开的文件）
c ➜ +代码
f ➜ +文件 / 查找
g ➜ +Git 版本控制
...
```

- 带 `+` 的是子菜单，按对应字母进入下一层
- `Backspace` 返回上一层，`Esc` 关闭
- 不只是空格，按 `g`、`[`、`]`、`z` 等前缀键也会弹出提示
- `空格 s k` 可以搜索所有快捷键

## 四、打开与管理文件

| 操作 | 按键 |
| --- | --- |
| 按文件名查找并打开（最常用） | `空格 空格` 或 `空格 f f` |
| 最近打开的文件 | `空格 f r` |
| 打开或关闭文件树 | `空格 e` |
| 新建文件 | `空格 f n` |
| 切换到上一个 / 下一个已打开的文件 | `Shift+h` / `Shift+l` |
| 关闭当前文件 | `空格 b d` |

**文件树里的操作**：`Enter` 打开，`a` 新建文件（名字以 `/` 结尾则新建目录），`d` 删除，`r` 重命名，`?` 查看全部操作。

**搜索窗口里的操作**：直接输入关键字过滤，`Ctrl+j` / `Ctrl+k` 或方向键上下选择，`Enter` 打开，`Esc` 关闭。

## 五、搜索

| 操作 | 按键 |
| --- | --- |
| 在整个项目里搜索文字 | `空格 /` |
| 在当前文件里搜索 | `/` 输入关键字，回车；`n` 跳到下一个，`N` 跳到上一个 |
| 项目内批量搜索替换 | `空格 s r` |
| 快速跳到屏幕上任意位置 | `s`，再输入目标处的一两个字符，然后按屏幕上显示的标签字母 |

## 六、写代码（LSP 功能）

| 操作 | 按键 |
| --- | --- |
| 自动补全 | 打字时自动弹出；`Ctrl+n` / `Ctrl+p` 或方向键选择，`Enter` 确认 |
| 查看文档 / 类型 | 光标移到变量上，按 `K` |
| 跳转到定义 | `g d`；按 `Ctrl+o` 跳回原来的位置 |
| 查找所有引用 | `g r` |
| 重命名变量（全项目同步） | `空格 c r` |
| 代码操作（快速修复、补 import 等） | `空格 c a` |
| 手动格式化 | `空格 c f`（保存时也会自动格式化） |
| 查看当前行的错误详情 | `空格 c d` |
| 跳到下一个 / 上一个错误 | `] d` / `[ d` |
| 查看项目内所有问题 | `空格 x x` |
| 整理 import（TS / Vue） | `空格 c o` |
| 注释或取消注释当前行 | `g c c`；可视模式下选中多行后按 `g c` |

## 七、编辑技巧（vim 的精髓）

vim 的编辑命令可以像句子一样组合：**动作 + 范围**。

| 动作 | 含义 |
| --- | --- |
| `d` | 删除（同时存入剪贴板，相当于"剪切"） |
| `c` | 修改（删除后自动进入插入模式） |
| `y` | 复制 |

| 范围 | 含义 |
| --- | --- |
| `w` | 到下一个单词 |
| `i w` | 光标所在的整个单词 |
| `i "` | 引号里面的内容 |
| `i (` 或 `i b` | 括号里面的内容 |
| `a f` | 整个函数 |
| `i t` | HTML/Vue 标签里面的内容 |

组合起来：

- `d i w`：删除当前单词
- `c i "`：修改引号里的内容
- `y a f`：复制整个函数
- `d d`：删除整行，`y y`：复制整行，`p`：粘贴

按下 `d`、`c`、`y` 之后稍等，which-key 也会弹出所有可用的范围。

## 八、窗口与终端

| 操作 | 按键 |
| --- | --- |
| 左右分屏 / 上下分屏 | `空格 \|` / `空格 -` |
| 在窗口之间移动 | `Ctrl+h/j/k/l`（左 / 下 / 上 / 右） |
| 关闭当前窗口 | `空格 w d` |
| 打开或关闭浮动终端 | `Ctrl+/` |

## 九、Git

| 操作 | 按键 |
| --- | --- |
| 打开 lazygit（完整的 Git 界面） | `空格 g g` |
| 查看当前行是谁改的 | `空格 g b` |
| 跳到下一个 / 上一个改动块 | `] h` / `[ h` |
| 预览改动 | `空格 g h p` |
| 撤销当前改动块 | `空格 g h r` |

编辑器左侧的彩色竖条表示与 Git 相比有改动的行。

## 十、剪贴板

- 在 nvim 里 `y` 复制的内容，可以直接在本机任何程序里粘贴（通过 OSC 52 协议）
- 把本机剪贴板的内容贴进 nvim：先按 `i` 进入插入模式，再按 Ghostty 的粘贴键（macOS 为 `Cmd+V`）

## 十一、遇到问题时

| 情况 | 做法 |
| --- | --- |
| 界面卡在奇怪的状态 | 多按几次 `Esc` |
| 想看某个功能的快捷键 | 按 `空格` 看菜单，或用 `空格 s k` 搜索 |
| 语言服务器似乎没工作 | `空格 c l` 查看当前文件连接了哪些语言服务器 |
| 查看已安装的插件或工具 | `空格 l`（插件）/ `:Mason`（工具） |
| 全面体检 | `:checkhealth`（可以忽略的警告见 `01-配置说明.md` 第五节） |
| 系统地学习 vim | 在 nvim 里运行 `:Tutor`（交互式教程，英文，约 30 分钟） |
